= Actions de sauvegarde et de restauration NetApp auditées
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Utilisez cette référence pour voir quelles actions de sauvegarde et de restauration NetApp Backup and Recovery la NetApp Console enregistre sur la page d'audit. Pour plus de détails sur l'affichage et le filtrage des événements d'audit, consultez  https://docs.netapp.com/us-en/console-setup-admin/task-monitor-cm-operations.html#audit-user-activity-from-the-audit-page["Audit de l'activité des utilisateurs depuis la page d'audit"^] la documentation de la NetApp Console.

Pour chaque action auditée, NetApp Console enregistre le nom du service, l’agent, la ressource, l’utilisateur et l’état de l’action.

[cols="1,3"]
|===
| Catégorie | Actions 


| Restauration et récupération  a| 
* Restaurer les fichiers à partir d'un instantané
* Restaurez le volume ou les fichiers à partir de la sauvegarde
* Restaurer le volume à partir d'un instantané
* Lancer l'exploration de fichiers




| opérations de sauvegarde et d'instantané  a| 
* Créer une sauvegarde cloud ad hoc
* Créer un instantané ad hoc
* Supprimer la stratégie d’instantané Azure NetApp Files
* Activer la sauvegarde dans un volume
* Actualiser les métadonnées de sauvegarde du volume (planifié)




| Protection et réplication  a| 
* Initialiser la protection du système
* Initialiser la protection de la source
* Initialiser la protection de la cible
* Groupes de pairs pour la protection
* Démarrez la réplication du volume




| Protection panoramique  a| 
* Activer la protection panoramique dans un système
* Activer la protection panoramique pour les volumes
* Modifier la protection panoramique pour les volumes
* Modifier la protection panoramique dans un système




| Migration des sauvegardes  a| 
* Migrer les sauvegardes entre les systèmes ONTAP
* Valider la migration de sauvegarde




| Gestion de Cyber Vault  a| 
* Créer un système Cyber Vault
* Supprimer le système Cyber Vault
* Désactiver l'accès à Cyber Vault
* Activer l'accès à Cyber Vault




| Gestion du stockage d'objets  a| 
* Créer un compartiment de stockage d'objets
* Modifier le compartiment de stockage d'objets
* Modifier le stockage d'objets pour le système




| Gestion des identifiants cloud  a| 
* Supprimer les identifiants cloud
* Enregistrez des identifiants cloud
* Mettre à jour les identifiants cloud




| Découverte et configuration  a| 
* Découvrez les volumes et les relations
* Mettre à jour la configuration de l'application


|===
