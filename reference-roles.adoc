= NetApp Backup and Recovery rôles IAM
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Utilisez la gestion des identités et des accès (IAM) pour contrôler quelles fonctionnalités et actions de NetApp Backup and Recovery chaque utilisateur peut utiliser.

Pour en savoir plus sur les rôles IAM spécifiques à NetApp Backup and Recovery, consultez https://docs.netapp.com/us-en/console-setup-admin/reference-iam-backup-rec-roles.html["Rôles de NetApp Backup and Recovery dans la NetApp Console"^].
