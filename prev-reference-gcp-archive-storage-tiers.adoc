NetApp Backup and Recovery prend en charge le niveau Archive de Google Cloud Storage pour les sauvegardes plus anciennes. Découvrez les coûts et les délais de restauration pour les sauvegardes de ce niveau.



[[supported-google-archival-storage-classes-for-netapp-backup-and-recovery]]
== Classes de stockage d'archivage Google prises en charge pour NetApp Backup and Recovery

Lors de leur création, les fichiers de sauvegarde sont initialement stockés dans un stockage _Standard_. Ce niveau est optimisé pour le stockage de données rarement consultées, tout en permettant un accès immédiat.

Si votre cluster sur site utilise ONTAP 9.12.1 ou une version ultérieure, vous pouvez hiérarchiser les sauvegardes plus anciennes vers le stockage _Archive_ dans l’interface utilisateur de NetApp Backup and Recovery après un certain nombre de jours (généralement plus de 30 jours) afin d’optimiser davantage les coûts. Les données de ce niveau ont un coût de récupération plus élevé ; tenez donc compte de la fréquence à laquelle vous pourriez avoir besoin de restaurer des données à partir de ces fichiers de sauvegarde archivés. Consultez la section de cette page sur la restauration des données à partir du stockage d’archivage.

Lorsque vous configurez NetApp Backup and Recovery avec ce type de règle de cycle de vie, ne configurez aucune règle de cycle de vie lors de la configuration du compartiment dans votre compte Google.

https://cloud.google.com/storage/docs/storage-classes["En savoir plus sur les classes de stockage Google"^].

== Restaurer les données à partir du stockage d'archives

Stocker d'anciens fichiers de sauvegarde dans le stockage Archive coûte beaucoup moins cher que dans le stockage Standard. Cependant, la restauration des données à partir d'un fichier de sauvegarde dans le stockage Archive prend légèrement plus de temps et coûte plus cher.

Combien coûte la restauration des données de Google Archive ?:: Pour connaître les tarifs détaillés de Google Cloud Storage par région, visitez le https://cloud.google.com/storage/pricing["Page de tarification de Google Cloud Storage"^] .
Combien de temps faudra-t-il pour restaurer mes objets archivés dans Google Archive ?:: Le temps total de restauration comporte deux parties :
+
--
* *Temps de récupération* : Le temps nécessaire pour récupérer le fichier de sauvegarde de l'archive et le placer dans le stockage standard.  C'est ce qu'on appelle parfois le temps de « réhydratation ».  Contrairement aux solutions de stockage « les plus froides » fournies par d’autres fournisseurs de cloud, vos données sont accessibles en quelques millisecondes.
* *Durée de restauration* : temps nécessaire pour restaurer les données à partir du fichier de sauvegarde stocké sur le stockage Standard. Ce temps est identique à celui d'une restauration classique effectuée directement depuis le stockage Standard sans niveau d'archivage.


--


[NOTE]
====
La restauration d'un volume ou d'un fichier à partir d'un stockage d'archive peut prendre plus de temps. La tâche reste *En cours* dans le Moniteur de tâches pendant que Backup and Recovery réessaie la restauration en fonction de la priorité sélectionnée. Surveillez la restauration dans le *Moniteur de tâches* ; elle se termine lorsque la tâche atteint un état final, tel que *Terminée* ou *Échec*, après toutes les tentatives de restauration. Ne lancez pas une autre restauration à moins que la tâche n'échoue finalement.
