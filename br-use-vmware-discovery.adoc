= Découvrez les charges de travail VMware avec NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs:

[role="lead"]
Avant de pouvoir protéger les datastores VMware et les machines virtuelles exécutées sur des systèmes ONTAP, vous devez les découvrir dans NetApp Backup and Recovery. Vous pouvez également importer des données de sauvegarde et des stratégies depuis SnapCenter.

*Rôle requis dans la NetApp Console* Super administrateur de NetApp Backup and Recovery. En savoir plus sur link:reference-roles.html["Rôles et privilèges de sauvegarde et de récupération"]. https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["En savoir plus sur les rôles d'accès à la NetApp Console pour tous les services"^].



[[discover-vmware-workloads-and-optionally-import-snapcenter-plug-in-resources]]
== Découvrez les charges de travail VMware et, si vous le souhaitez, importez les ressources du plug-in SnapCenter

Lors de la phase de découverte, NetApp Backup and Recovery analyse les charges de travail VMware au sein de votre organisation, évalue et importe les politiques de protection, les instantanés et les options de sauvegarde et de restauration existants.

Si vous utilisez le plug-in SnapCenter pour VMware vSphere sur site, vous pouvez importer des banques de données VMware et des machines virtuelles de ressources dans NetApp Backup and Recovery.


NOTE: Après avoir ajouté un système de stockage à NetApp Console, patientez quelques minutes avant de découvrir les ressources. Découvrir les ressources immédiatement après avoir ajouté un système de stockage peut entraîner l'échec de la découverte.


NOTE: NetApp Backup and Recovery prend en charge uniquement VMware vCenter et ne découvre pas les vVols ni les machines virtuelles sur vVols.

Pendant le processus d’importation, NetApp Backup and Recovery effectue les tâches suivantes :

* Active l'accès SSH sécurisé au serveur vCenter.
* Active le mode de maintenance sur tous les groupes de ressources du serveur vCenter.
* Prépare les métadonnées du vCenter et les marque comme non gérées dans la NetApp Console.
* Configure l'accès à la base de données.
* Découvre VMware vCenter, les banques de données et les machines virtuelles.
* Importe les politiques de protection, les instantanés et les options de sauvegarde et de restauration existants à partir du SnapCenter Plug-in for VMware vSphere.
* Affiche les ressources découvertes dans la page Inventaire de NetApp Backup and Recovery .


La découverte se déroule de la manière suivante :

* Si vous possédez déjà SnapCenter ou le SnapCenter Plug-in pour VMware vSphere, importez les ressources SnapCenter dans NetApp Backup and Recovery à l'aide de l'interface utilisateur NetApp Backup and Recovery.
+

NOTE: Si vous possédez déjà le SnapCenter Plug-in, assurez-vous d’avoir rempli les conditions préalables avant d’importer depuis SnapCenter. Par exemple, vous devez d’abord créer des systèmes dans NetApp Console pour tout le stockage de cluster SnapCenter sur site avant d’importer depuis SnapCenter. Voir link:concept-start-prereq-snapcenter-import.html["Conditions préalables à l'importation de ressources depuis SnapCenter"]. Pour importer des données directement depuis un hôte SnapCenter, reportez-vous à link:br-start-configure.html#import-and-manage-snapcenter-host-resources["Importer et gérer les ressources de l'hôte SnapCenter"].

* Si vous ne disposez pas déjà du plug-in SnapCenter , vous pouvez toujours découvrir les charges de travail au sein de vos systèmes en ajoutant un vCenter manuellement et en effectuant la découverte.




[[if-not-using-the-snapcenter-plug-in-add-a-vcenter-and-discover-resources]]
=== Si vous n'utilisez pas le plug-in SnapCenter, ajoutez un vCenter et découvrez les ressources

Si vous n'avez pas le SnapCenter Plug-in for VMware installé, ajoutez les informations vCenter afin que NetApp Backup and Recovery puisse découvrir les charges de travail. Dans chaque agent Console, sélectionnez les systèmes où vous souhaitez découvrir les charges de travail.

.Étapes
. Dans la navigation de gauche de la NetApp Console , sélectionnez *Protection* > *Sauvegarde et récupération*.
. Sélectionnez *Découvrir les ressources*.
. Saisissez les informations suivantes :
+
.. *Type de charge de travail* : sélectionnez *VMware*.
.. *Paramètres vCenter* : Procédez comme suit :
+
... Si vous n'avez pas encore enregistré d'identifiants pour ce vCenter serveur, sélectionnez *Ajouter des identifiants*.
+
**** Sélectionnez l’agent de Console à utiliser avec ce vCenter.
**** Saisissez un nom pour ces informations d’identification.
**** Saisissez le domaine, le nom d'utilisateur et le mot de passe du compte.
**** Sélectionnez *Terminé*.


... Saisissez le FQDN ou l'adresse IP de vCenter, sélectionnez un agent Console et sélectionnez les identifiants à utiliser pour vous authentifier auprès de vCenter.
+

TIP: Si vous saisissez des informations vCenter, saisissez les informations relatives aux paramètres vCenter et à l’enregistrement de l’hôte.  Si vous avez ajouté ou saisi des informations sur vCenter ici, vous devez également ajouter des informations sur le plug-in dans les paramètres avancés.



.. *Paramètres avancés* : Vous pouvez, si vous le souhaitez, indiquer un port à utiliser pour la communication avec vCenter et activer l’utilisation de certificats auto-signés. L’utilisation de certificats auto-signés est déconseillée en environnement de production.


. Sélectionnez *Découvrir*.




[[import-snapcenter-plug-in-for-vmware-resources-into-netapp-backup-and-recovery]]
=== Importez le plug-in SnapCenter pour les ressources VMware dans NetApp Backup and Recovery

Importez les ressources du NetApp SnapCenter Plug-in for VMware dans NetApp Backup and Recovery. Lors de l'importation, la Console découvre vos hôtes ESXi, banques de données, machines virtuelles et planifications, vous n'avez donc pas besoin de les recréer manuellement.

Vous pouvez le faire des manières suivantes :

* Lors de la découverte, sélectionnez l’option pour importer les ressources à partir du SnapCenter Plug-in.
* Après la découverte, à partir de la page Inventaire, sélectionnez une option pour importer les ressources du plug-in SnapCenter .
* Après la découverte, dans le menu Paramètres, sélectionnez une option pour importer les ressources du plug-in SnapCenter. Pour plus de détails, consultez link:br-start-configure.html["Configurer la NetApp Backup and Recovery"].


Il s’agit d’un processus en deux parties décrit dans cette section :

. Importez les métadonnées vCenter depuis le plug-in SnapCenter . Les ressources vCenter importées ne sont pas encore gérées par NetApp Backup and Recovery.
. Lancez la gestion des vCenters, des machines virtuelles et des banques de données sélectionnés dans NetApp Backup and Recovery. Après avoir lancé la gestion, NetApp Backup and Recovery marque le vCenter comme « Géré » sur la page Inventaire et peut sauvegarder et restaurer les ressources que vous avez importées. Après avoir lancé la gestion dans NetApp Backup and Recovery, vous ne gérez plus ces ressources à l’aide du plug-in SnapCenter.




==== Importer les métadonnées vCenter à partir du plug-in SnapCenter

Cette première étape importe les métadonnées vCenter depuis le plug-in SnapCenter . À ce stade, les ressources ne sont pas encore gérées par NetApp Backup and Recovery.


TIP: Une fois que vous avez importé les métadonnées vCenter à partir du plug-in SnapCenter , NetApp Backup and Recovery ne prend pas automatiquement en charge la gestion de la protection.  Pour ce faire, vous devez choisir explicitement de gérer les ressources importées dans NetApp Backup and Recovery.  Cela garantit que vous êtes prêt à ce que ces ressources soient sauvegardées par NetApp Backup and Recovery.

.Étapes
. Dans la navigation de gauche de la console, sélectionnez *Protection* > *Sauvegarde et récupération*.
. Sélectionnez *Paramètres*.
. Sélectionnez *Importer depuis SnapCenter > Importer depuis SnapCenter*.
. Dans le champ Importer depuis, sélectionnez *SnapCenter Plug-in for VMware (SCV)*.
. Saisissez les SnapCenter Plug-in for VMware host credentials* :
+
Si le SnapCenter Plug-in est déjà enregistré, vous pouvez mettre à jour les informations d'enregistrement existantes.

+
** *Adresse IP* : Saisissez l’adresse IP du SnapCenter Plug-in for VMware vSphere.
** *Numéro de port* : Saisissez le numéro de port pour le plug-in.
** *Nom d'utilisateur* et *Mot de passe* : Saisissez le nom d'utilisateur et le mot de passe que vous avez créés lors du déploiement de l'OVA.
** *Mot de passe SSH* : Saisissez le mot de passe SSH pour l’utilisateur root si SSH est activé.
** *Agents* : Sélectionnez l’agent Console utilisé avec le Plug-in.


. Saisissez les *informations d'identification VMware vCenter* :
+
** *Informations d'identification existantes* : si vous sélectionnez cette option, vous pouvez utiliser les informations d'identification existantes que vous avez déjà ajoutées.  Choisissez le nom des informations d'identification.
** *Ajouter de nouveaux identifiants* : Si vous ne disposez pas déjà d’identifiants vCenter, vous pouvez en ajouter de nouveaux. Saisissez les informations suivantes :
+
*** *Nom des identifiants* : Saisissez le nom de ce nouvel ensemble d’identifiants.
*** *vCenter IP/nom d'hôte* : saisissez le nom de domaine complet ou l'adresse IP du vCenter que vous souhaitez importer dans NetApp Backup and Recovery.
*** *Nom d'utilisateur vCenter* et *Mot de passe* : saisissez le nom d'utilisateur et le mot de passe du vCenter.
*** *Numéro de port vCenter* : saisissez le numéro de port du vCenter.




. Sélectionnez *Importer* pour valider vos entrées et enregistrer le plug-in SnapCenter .


.Résultat
La page Inventaire affiche le vCenter comme non géré dans NetApp Backup and Recovery jusqu'à ce que vous choisissiez explicitement de le gérer.



==== Gérer les ressources importées depuis le plug-in SnapCenter

Après avoir importé les métadonnées vCenter depuis le SnapCenter Plug-in pour VMware, gérez les ressources dans NetApp Backup and Recovery. Après avoir choisi de gérer ces ressources, NetApp Backup and Recovery peut sauvegarder et restaurer les ressources que vous avez importées. Après avoir lancé la gestion dans NetApp Backup and Recovery, vous ne gérez plus ces ressources dans le SnapCenter Plug-in.

Après avoir choisi de gérer les ressources, NetApp Backup and Recovery importe les ressources, les machines virtuelles et les stratégies depuis le SnapCenter Plug-in for VMware. Les groupes de ressources, les stratégies et les instantanés sont migrés depuis le Plug-in et deviennent gérés dans NetApp Backup and Recovery.

.Étapes
. Après avoir importé les ressources VMware à partir du SnapCenter Plug-in, sélectionnez *Inventaire* dans le menu Sauvegarde et restauration.
. Sur la page Inventaire, sélectionnez le vCenter importé que vous souhaitez que NetApp Backup and Recovery gère.
. Sélectionnez l'icône Actionsimage:../media/icon-action.png["Option Actions"] > *Afficher les détails* pour afficher les détails de la charge de travail.
. Depuis la page Inventaire > charge de travail, sélectionnez l'icône Actions image:../media/icon-action.png["Option Actions"] > *Gérer* pour ouvrir la page Gérer vCenter.
. Cochez la case « Do you want to continue with the migration? » et sélectionnez *Manage*.


.Résultat
La page Inventaire affiche les ressources vCenter nouvellement gérées.
