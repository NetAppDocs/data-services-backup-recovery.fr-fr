= Protégez les charges de travail de base de données Oracle avec NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Utilisez NetApp Backup and Recovery pour protéger les charges de travail et journaux Oracle Database avec des sauvegardes et restaurations rapides, économes en espace, cohérentes après panne et cohérentes au niveau de la base de données. Vous pouvez sauvegarder les charges de travail sur AWS S3, StorageGRID, Azure Blob ou ONTAP S3 et restaurer les sauvegardes sur un hôte Oracle local.

Utilisez NetApp Backup and Recovery pour mettre en œuvre une stratégie de protection 3-2-1, consistant à conserver trois copies de vos données sources sur deux systèmes de stockage différents, ainsi qu'une copie dans le cloud. Les avantages de l'approche 3-2-1 sont les suivants :

* Plusieurs copies de données protègent contre les menaces de cybersécurité internes et externes.
* Différents types de supports vous aident à récupérer si l’un des types tombe en panne.
* Vous pouvez restaurer rapidement à partir de la copie sur site et utiliser les copies hors site si la copie sur site est compromise.




[[oracle-data-guard-support]]
== Prise en charge d'Oracle Data Guard

NetApp Backup and Recovery peut protéger les configurations Oracle Data Guard comportant une base de données primaire à instance unique et une base de données physique de secours à l'état monté.
