= Flux de travail de protection Kubernetes avec NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Utilisez NetApp Backup and Recovery pour découvrir, gérer et protéger les clusters et applications Kubernetes à partir d'une interface unique.

Le diagramme suivant illustre les composants et l'architecture de base de la sauvegarde et de la restauration Kubernetes, ainsi que la manière dont des copies de vos données peuvent être stockées à différents emplacements :

image:../media/backup-recovery-architecture-diagram.png["Diagramme d'architecture de sauvegarde et de restauration pour les charges de travail Kubernetes"]

NetApp Backup and Recovery offre les avantages suivants pour la gestion des charges de travail Kubernetes :

* Un plan de contrôle unique pour la protection des applications sur plusieurs clusters Kubernetes, y compris les conteneurs et les machines virtuelles.
* L'intégration native avec NetApp SnapMirror permet le déchargement du stockage pour les flux de travail de sauvegarde et de restauration.
* Sauvegardes incrémentielles permanentes pour les applications Kubernetes, se traduisant par des objectifs de point de récupération (RPO) et des objectifs de temps de récupération (RTO) inférieurs.

* link:br-use-protect-kubernetes-applications.html["Ajoutez et protégez les applications Kubernetes dans NetApp Backup and Recovery"].
* link:br-use-manage-kubernetes-applications.html["Gérez les applications Kubernetes dans NetApp Backup and Recovery"].
