= Gérez les applications Kubernetes dans NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Désactivez la protection ou supprimez les applications Kubernetes et supprimez les points de restauration si nécessaire.

*Rôle de NetApp Console requis*

Super administrateur NetApp Backup and Recovery ou administrateur de sauvegarde NetApp Backup and Recovery. link:reference-roles.html["En savoir plus sur les rôles d'accès à NetApp Backup and Recovery"]. https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["En savoir plus sur les rôles d'accès à la NetApp Console pour tous les services"^].



[[unprotect-a-kubernetes-application]]
== Déprotéger une application Kubernetes

Vous pouvez désactiver la protection d'une application si vous n'avez plus besoin de la protéger. Lorsque vous désactivez la protection d'une application, NetApp Backup and Recovery cesse de protéger l'application, mais conserve toutes les sauvegardes et tous les instantanés associés.


NOTE: Vous ne pouvez pas déprotéger une application tant que des opérations de protection sont en cours. Attendez la fin de l'opération ou supprimez le point de restauration utilisé par l'opération de protection en cours. Vous pouvez ensuite déprotéger l'application.

.Étapes
. Dans NetApp Backup and Recovery, sélectionnez *Inventaire*.
. Sélectionnez une instance Kubernetes, puis sélectionnez *Afficher* pour ouvrir les ressources associées à cette instance.
. Sélectionnez l'onglet *Applications*.
. Dans la liste des applications, sélectionnez l'application que vous souhaitez déprotéger et sélectionnez le menu Actions associé.
. Sélectionnez *Déprotéger*.
. Lisez l'avis et, lorsque vous êtes prêt, sélectionnez *Déprotéger*.




[[delete-a-kubernetes-application]]
== Supprimer une application Kubernetes

Supprimez une application dont vous n'avez plus besoin. NetApp Backup and Recovery désactive la protection et supprime toutes les sauvegardes et tous les instantanés des applications supprimées.

.Étapes
. Dans NetApp Backup and Recovery, sélectionnez *Inventaire*.
. Sélectionnez une instance Kubernetes, puis sélectionnez *Afficher* pour ouvrir les ressources associées à cette instance.
. Sélectionnez l'onglet *Applications*.
. Dans la liste des applications, sélectionnez l'application que vous souhaitez supprimer et sélectionnez le menu Actions associé.
. Sélectionnez *Supprimer*.
. Activez l'option *Supprimer les instantanés et les sauvegardes* pour supprimer tous les instantanés et toutes les sauvegardes de l'application.
+

CAUTION: Vous ne pourrez plus restaurer l'application à l'aide de ces instantanés et sauvegardes.

. Confirmez l'action et sélectionnez *Supprimer*.




[[remove-a-restore-point-for-a-kubernetes-application]]
== Supprimer un point de restauration pour une application Kubernetes

Supprimez un point de restauration pour une application si vous devez la déprotéger pendant que des opérations de protection sont en cours.

.Étapes
. Dans le menu NetApp Backup and Recovery, sélectionnez *Restaurer*.
. Sélectionnez une application Kubernetes dans la liste, puis sélectionnez *Afficher et restaurer* pour ouvrir ses points de restauration.
. Sélectionnez le point de récupération que vous souhaitez supprimer et sélectionnez l’icône Actions image:../media/icon-action.png["Option Actions"] > *Supprimer le point de récupération* pour le supprimer.
